FMEA - SOFTWARE FAILURE MODE EFFECT AND ANALYSIS 

PURPOSE 

Software Failure Mode and Effects Analysis (sFMEA) is a bottom-up method for identifying how a software function or component can fail, 
what effects result, and  what controls can prevent or detect it.

sFMEA is used by coding agent to reason about potential failures 

sFMEA does not establish that a failure exists. It produces failure hypotheses that should be verified against code, tests or other evidence

FAILURE MODE AND EFFECT 
For each failure formulated  map a software failure mode to a function or component/module: 

For each failure mode ask and reason about the effects of failure mode
If this failure occurs, what does it impact?

- Does it stay local?
- Does it propagate to callers?
- Does it corrupt shared state?
- Does it cause an exception?
- Is the exception handled?
- Does it cause a retry?
- Does retry amplify the failure?
- Does it affect another subsystem?
